Overview

What affects a television's energy use?

Screen Size

Larger screens may require more energy than smaller screens, although actual consumption depends on the model and display technology.

Brightness

Higher brightness settings can increase energy use. Using automatic brightness or energy-saving modes may reduce consumption.

Daily Viewing Time

A television used for many hours each day will generally consume more electricity over a year than one used occasionally.

D3 setup and responsive SVG

We first use D3 to append an SVG to the page and add a rectangle. The SVG viewBox controls its coordinate system.

Exercise 4.5

Bind data to rectangles

D3 uses .data(data).join("rect") to draw one horizontal bar for each brand. This first version uses the raw count as the bar width, before adding scales.

Code to explain: .data() binds CSV rows to SVG elements and .join() creates or updates rectangles.

Exercise 4.6

Apply linear and band scales

The horizontal scaleLinear() converts counts to pixel widths. The vertical scaleBand() positions categories evenly and controls spacing.

Code to explain: domain() refers to the data values and range() refers to the drawing coordinates.

Exercise 4.7

Final bar chart with brand and count labels

The final version combines the scaled bars, brand names and numeric count labels. The bars are sorted from highest to lowest for easier comparison.

Code to explain: each g contains a rectangle, a brand label and its count. The transform="translate(...)" positions each group.
